# THƯ MỤC CHỨA ỨNG DỤNG ĐẦU VÀO

Hãy kéo thả file bạn muốn phân tích vào đây:
- File cài đặt Android (`.apk`)
- File nén mã nguồn hoặc thư viện (`.zip`, `.rar`, `.tar.gz`)
- Thư mục mã nguồn dự án
- File gói ứng dụng Desktop (`.asar`, `.exe` cài đặt nội bộ)
- Hoặc tạo 1 file `link.txt` chứa đường dẫn website cần kiểm tra

Sau khi thả file xong, mở chat với AI và yêu cầu kiểm tra.
