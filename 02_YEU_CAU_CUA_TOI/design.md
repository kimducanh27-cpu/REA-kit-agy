# HỢP ĐỒNG THIẾT KẾ GIAO DIỆN & DESIGN TOKENS CỦA TÔI
*(Người dùng: Tùy chỉnh màu sắc hoặc font chữ bạn thích tại đây. AI sẽ tự động áp dụng vào ứng dụng)*

---

## 1. Phong cách mong muốn
- **Tên phong cách:** Hiện đại & Tối giản (Modern Clean)
- **Chế độ hiển thị:** Light Mode (Sáng)

---

## 2. Bảng màu ứng dụng (CSS Tokens)
```css
:root {
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-background: #f8fafc;
  --color-surface: #ffffff;
  --color-border: #e2e8f0;
  --color-text-main: #0f172a;
  --color-text-muted: #64748b;
  --color-accent: #10b981;
  --color-danger: #ef4444;
}
```

---

## 3. Phông chữ & Bo góc
```css
:root {
  --font-main: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
  --radius-md: 10px;
}
```
